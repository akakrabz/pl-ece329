At distance $d$ from the sheet, with $\hat{n}$ the unit normal pointing from the sheet toward the field point: $\mathbf{E} = -\tfrac{\eta}{2}\,\mathbf{J}_s(t-d/v_p)$ and $\mathbf{H} = \tfrac12\,\mathbf{J}_s(t-d/v_p)\times\hat{n}$, with $\eta = \eta_0/\sqrt{\epsilon_r}$ and $v_p = c/\sqrt{\epsilon_r}$. For a cosine current, $\cos\big(\omega(t-d/v_p)\big) = \cos(\omega t-\beta d)$ with $\beta = \omega/v_p$. Write $\mathbf{J}_s$ as a vector with its sign, evaluate the cosine at the point and instant, and do the cross product with the $\hat{n}$ of that side. Check: $\mathbf{E}\times\mathbf{H}$ must point away from the sheet.

(a) $v_p = c/\sqrt{\epsilon_r} = (3\times10^{8})/{{params.n_str}} = {{params.vp8_str}}\times10^{8}\ \mathrm{m/s}$; $\lambda = v_p/f = {{params.lam_str}}\ \mathrm{m}$; $\beta = \omega/v_p = 2\pi/\lambda = {{params.beta_str}}\ \mathrm{rad/m}$.

(b) The point is on the side ${{{params.side_tex}}}$, at distance $d = {{params.absw1_str}}\ \mathrm{m}$, where $\hat{n} = {{{params.nhat}}}$. The phase there is $\omega t-\beta d = {{params.wt_str}} - {{params.bw_str}}\ \mathrm{rad}$, which is ${{{params.ph_tex}}}$ modulo $2\pi$, so $\cos(\omega t-\beta d) = {{params.cph_str}}$ and $\mathbf{J}_s(t-d/v_p) = {{params.Js_now_str}}\,\hat{ {{params.a}} }\ \mathrm{A/m}$. With $\eta = \eta_0/\sqrt{\epsilon_r} = {{params.eta_str}}\ \Omega$: $$E_{ {{params.a}} } = -\frac{\eta}{2}\,({{params.Js_now_str}}) = {{params.Ea_str}}\ \mathrm{V/m},\qquad \mathbf{H} = \tfrac12\,({{params.Js_now_str}})\,\hat{ {{params.a}} }\times({{{params.nhat}}}),\quad \hat{ {{params.a}} }\times\hat{ {{params.w}} } = {{{params.aw_cross}}},\quad H_{ {{params.b}} } = {{params.Hb_str}}\ \mathrm{A/m}.$$ $\mathbf{E}$ opposes the sheet current at the retarded time; $\lvert\mathbf{E}\rvert/\lvert\mathbf{H}\rvert = \eta$.

(c) $\mathbf{S} = \mathbf{E}\times\mathbf{H}$ gives $S_{ {{params.w}} } = {{params.Sw_str}}\ \mathrm{W/m^2}$, which equals $\tfrac{\eta}{4}J_0^2\cos^2(\omega t-\beta d)$ along $\hat{n} = {{{params.nhat}}}$: away from the sheet, as it must be for an outgoing wave.

(d) At ${{params.w}} = {{params.mw1_str}}\ \mathrm{m}$ the distance and hence the phase are the same, $\mathbf{E}$ is identical, and $\mathbf{H}$ is reversed because $\hat{n} = {{{params.nhat_other}}}$ there. So $\mathbf{S}$ has the same magnitude and points along ${{{params.nhat_other}}}$, again away from the sheet. $\mathbf{E}$ is even across the sheet (tangential $\mathbf{E}$ is continuous) and $\mathbf{H}$ is odd (its tangential jump is the sheet current). $\mathbf{S}$ is never zero by cancellation: each half-space has only its own outgoing wave. And $\mathbf{S}\perp\mathbf{E}\parallel\mathbf{J}_s$.
