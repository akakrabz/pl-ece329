Throughout, every medium is non-magnetic ($\mu = \mu_0$), its $\sigma$ and $\epsilon = \epsilon_r\epsilon_0$ are the handbook values given and are treated as independent of frequency, and $\omega = 2\pi f$. Use $\mu_0 = 4\pi\times10^{-7}\ \mathrm{H/m}$ and $\epsilon_0 = 8.854\times10^{-12}\ \mathrm{F/m}$. At a given frequency a medium counts as a good conductor if $\sigma/\omega\epsilon \gt 10$ and as an imperfect dielectric if $\sigma/\omega\epsilon \lt 0.1$.

Compute $\sigma/\omega\epsilon$ with the medium's own $\epsilon = \epsilon_r\epsilon_0$ and with $\omega = 2\pi f$, not $f$. Equivalently, compare $f$ with the crossover $f_c = \sigma/2\pi\epsilon$: more than ten times below it, a good conductor; more than ten times above it, an imperfect dielectric. $\delta = 1/\sqrt{\pi f\mu\sigma}$, $\alpha = \beta = 1/\delta$, $\eta = (1+j)/(\sigma\delta) = \sqrt{\omega\mu/\sigma}\,e^{j45^\circ}$, $\lambda = 2\pi\delta$. The power density falls as $e^{-2\alpha d}$, which is $8.686\,\alpha d$ decibels.

(b) $\omega = 2\pi f = {{params.om_str}}\ \mathrm{rad/s}$ and $\omega\epsilon = {{params.omeps_str}}\ \mathrm{S/m}$, so $\sigma/\omega\epsilon = {{params.p_str}} \gg 10$: a good conductor, and the approximations hold. Then $\pi f\mu_0\sigma = {{params.pis_str}}\ \mathrm{m^{-2}}$, so $$\delta = \frac{1}{\sqrt{\pi f\mu_0\sigma}} = {{params.delta_str}}\ {{{params.d_u}}},\qquad \lvert\eta\rvert = \sqrt{\frac{\omega\mu_0}{\sigma}} = {{params.eta_str}}\ {{{params.e_u}}},$$ with $\eta = (1+j)/(\sigma\delta) = {{params.eta_re_str}}(1+j)\ {{{params.e_u}}}$: equal real and imaginary parts, angle $45^\circ$. (The lossless formula $\sqrt{\mu/\epsilon}$ would be far too large: conduction, not $\epsilon$, sets $\eta$ here.)

(c) $\ell/\delta = {{params.nd_str}}$. The power density falls as $e^{-2\ell/\delta}$, i.e. by $10\log_{10}e^{2\ell/\delta} = 8.686\,\ell/\delta = {{params.dB_str}}\ \mathrm{dB}$ (the field amplitude falls by the same number of decibels, $20\log_{10}e^{\ell/\delta}$); the attenuation rate is $8.686/\delta = {{params.dBpm_str}}\ \mathrm{dB/m}$. What is left is $100\,e^{-2\ell/\delta} = {{params.pct_str}}\ \%$. Using $e^{-\ell/\delta}$ (the field ratio) for the power is the classic slip.

(d) $\tilde{\mathbf{H}} = \hat{u}\times\tilde{\mathbf{E}}/\eta$ and $\angle\eta = 45^\circ$, so $\mathbf{H}$ lags $\mathbf{E}$ by $45^\circ$, one eighth of a period: $T/8 = {{{params.T8_str}}}$. It never leads (that would need $\sigma \lt 0$) and the lag never reaches $90^\circ$.

(e) $\beta = \alpha = 1/\delta$, so $\lambda = 2\pi/\beta = 2\pi\delta = {{{params.lam_str}}}$, and $e^{-\alpha\lambda} = e^{-2\pi} = 1/535$: the wave is essentially gone within one wavelength. Its phase velocity $v_p = \omega\delta = {{params.vp_str}}\ \mathrm{m/s}$ is tiny compared with $c$ and grows as $\sqrt{f}$ (dispersion).
