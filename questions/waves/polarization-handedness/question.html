Read the travel direction $\hat{u}$ from the exponent or the argument ($e^{-j\beta z}$ and $\omega t - \beta z$ travel toward $+z$; $e^{j\beta x}$ and $\omega t + \beta x$ toward $-x$). On the plane where the exponent is 1, take $\mathbf{E}(0) = \text{Re}\{\tilde{\mathbf{E}}\}$ and, a quarter period later, $\mathbf{E}(T/4) = -\text{Im}\{\tilde{\mathbf{E}}\}$ (for a real field: set $\omega t = 0$ and $\omega t = \pi/2$). Then $\hat{u}\cdot[\mathbf{E}(0)\times\mathbf{E}(T/4)]$ is positive for right-handed, negative for left-handed, zero for linear; the wave is circular when the two snapshots are perpendicular and equally long. In a lossless medium $\langle\mathbf{S}\rangle = \dfrac{\lvert\tilde{E}_a\rvert^2 + \lvert\tilde{E}_b\rvert^2}{2\eta}\,\hat{u}$, whatever the phase between the components. Plasma: $\omega_p^2 = Ne^2/(m_e\epsilon_0)$, $\beta = \tfrac1c\sqrt{\omega^2 - \omega_p^2}$, $v_p = \omega/\beta$, $v_g = d\omega/d\beta$, so $v_pv_g = c^2$.

(b) The wave travels toward ${{{params.trav_b}}}$, and $\eta = \eta_0/\sqrt{\epsilon_r} = 120\pi/{{params.n_str}} = {{params.eta_str}}\ \Omega$. Both components have amplitude $E_0 = {{params.E0}}\ \mathrm{V/m}$, so $$\langle S_{ {{params.ub}} }\rangle = {{params.sgn_b}}\frac{E_0^2 + E_0^2}{2\eta} = {{params.S_str}}\ \mathrm{mW/m^2},$$ the sign being that of the travel direction: twice the ${{params.S_one_str}}\ \mathrm{mW/m^2}$ that either linear component alone would carry. $\mathbf{H} = \hat{u}\times\mathbf{E}/\eta$ rotates with $\mathbf{E}$ at constant length $\lvert\mathbf{H}\rvert = E_0/\eta = {{params.H_str}}\ \mathrm{mA/m}$. Since $\lvert\mathbf{E}\rvert$ and $\lvert\mathbf{H}\rvert$ are constant and $\mathbf{E}\perp\mathbf{H}$, the instantaneous $\mathbf{S}$ is constant and equals $\langle\mathbf{S}\rangle$. A linearly polarized wave of the same amplitude would instead have an $\mathbf{S}$ that pulses at $2\omega$.

(c) $\omega_p = \sqrt{Ne^2/(m_e\epsilon_0)} = {{params.wp_str}}\ \mathrm{rad/s}$, so $f_p = \omega_p/2\pi = {{params.fp_str}}\ \mathrm{MHz}$, below the carrier: the wave propagates. With $f_p/f = {{params.ratio_str}}$, $\sqrt{1 - f_p^2/f^2} = {{params.root_str}}$, and $$v_p = \frac{c}{\sqrt{1 - f_p^2/f^2}} = {{params.vp_str}}\times10^{8}\ \mathrm{m/s},\qquad v_g = c\sqrt{1 - f_p^2/f^2} = {{params.vg_str}}\times10^{8}\ \mathrm{m/s},$$ and $v_pv_g = c^2$. The message rides the envelope, which travels at $v_g$: it needs $L/v_g = {{params.delay_str}}\ \mathrm{ms}$, against ${{params.vac_str}}\ \mathrm{ms}$ in vacuum. A crest would cross in ${{params.crest_str}}\ \mathrm{ms}$, but crests carry no information, so $v_p \gt c$ breaks nothing.
