Set $d\mathbf{v}/dt = 0$ in $m\,d\mathbf{v}/dt = q\mathbf{E} - m\mathbf{v}/\tau$: $\mathbf{v} = (q\tau/m)\mathbf{E}$. With $\mathbf{J} = Nq\mathbf{v}$ this is $\mathbf{J} = \sigma\mathbf{E}$ with $\sigma = Nq^2\tau/m$. A current density and the drift speed are tied by $J = N|q|v$. With phasors $d/dt \to j\omega$: $\sigma(\omega) = \dfrac{\sigma_{\text{DC}}}{1 + j\omega/\nu}$ with $\nu = 1/\tau$, so $|\sigma|/\sigma_{\text{DC}} = 1/\sqrt{1 + (\omega\tau)^2}$ and $\angle\sigma = -\arctan(\omega\tau)$. Lorentz model without damping: $\chi_e(\omega) = \dfrac{N_de^2/(m\epsilon_0)}{\omega_0^2 - \omega^2} = \dfrac{\chi_e(0)}{1 - \omega^2/\omega_0^2}$.

(a) $\sigma_{\text{DC}} = \dfrac{Ne^2\tau}{m_e} = \dfrac{({{params.N_str}}\times10^{28})(1.602\times10^{-19})^2({{params.tau_str}}\times10^{-15})}{9.109\times10^{-31}} = {{params.sigma_str}}\ \mathrm{MS/m}$, close to the measured room-temperature value for {{params.metal}}, about ${{params.sig_meas_str}}\ \mathrm{MS/m}$. The charge enters squared, so the sign of the carriers does not matter.

(b) Mobility $= e\tau/m_e = {{params.mob_si}}\ \mathrm{m^2/(V\,s)} = {{params.mob_str}}\ \mathrm{cm^2/(V\,s)}$. {{{params.b2}}} The drift is tiny compared with the electrons' random thermal speeds ($\sim10^5\ \mathrm{m/s}$), which average to zero and carry no current.

(c) $\omega\tau = 2\pi f\tau = 2\pi({{params.f_str}}\times10^{12})({{params.tau_str}}\times10^{-15}) = {{params.wt_str}}$. Then $\dfrac{|\sigma(\omega)|}{\sigma_{\text{DC}}} = \dfrac{1}{\sqrt{1 + (\omega\tau)^2}} = {{params.ratio_str}}$ and $\angle\sigma(\omega) = -\arctan(\omega\tau) = {{params.phase_str}}^\circ$: the current lags the field, because the electrons' inertia keeps them from following a field that reverses within a few collision times. At radio and microwave frequencies $\omega\tau \ll 1$ and $\sigma(\omega) \approx \sigma_{\text{DC}}$.

(e) Drude: $\tau$ is the mean time between collisions, $\sigma = Nq^2\tau/m$ is a property of the material (independent of $\mathbf{E}$), carriers of either sign conduct along $\mathbf{E}$, and with $\mathbf{E}$ removed the drift dies out as $e^{-t/\tau}$. The collision time is not the charge-relaxation time $\epsilon/\sigma$. Lorentz: the electron is displaced against $\mathbf{E}$, so $\mathbf{p} = -e\mathbf{r}$ points along $\mathbf{E}$, and $\chi_e(0) = N_de^2/(m\epsilon_0\omega_0^2)$. A changing $\mathbf{P}$ is a real current, $\mathbf{J}_p = \partial\mathbf{P}/\partial t$, which leads a sinusoidal $\mathbf{E}$ by $90^\circ$ and vanishes in a static field.
