A uniform, non-magnetic medium ($\mu = \mu_0$) fills all space. A plane electromagnetic pulse travels through it toward ${{params.dir_word}}$ at speed $v = {{params.v}}\ \mathrm{m/ns}$ ($= {{params.v_tex}}\ \mathrm{m/s}$), and is observed to keep exactly its shape and size as it travels. At $t = t_0 = {{params.t0}}\ \mathrm{ns}$ its electric field is $\mathbf{E}(z, t_0) = {{params.e_tex}}\,F(z)$, where the snapshot $F(z)$ (figure) is zero outside ${{params.zA}}\ \mathrm{m} \lt z \lt {{params.zD}}\ \mathrm{m}$. It changes linearly from $0$ at $z = {{params.zA}}\ \mathrm{m}$ to ${{params.E0}}\ \mathrm{V/m}$ at $z = {{params.zB}}\ \mathrm{m}$, {{{params.flat_desc}}}then returns linearly to $0$ at $z = {{params.zD}}\ \mathrm{m}$.

Positions are in metres and times in nanoseconds throughout. Use $c = 1/\sqrt{\mu_0\epsilon_0} = 2.998\times10^{8}\ \mathrm{m/s}$ and $\mu_0 = 4\pi\times10^{-7}\ \mathrm{H/m}$.

(e) Could this medium be a conductor ($\sigma \gt 0$)?

No. In a conductor the current $\mathbf{J} = \sigma\mathbf{E}$ dissipates energy, so the pulse would shrink and change shape as it travels. A pulse that travels unchanged at $v \lt c$ is in a lossless dielectric. Yes: only a conductor can make a wave travel slower than $c$. A pattern sliding rigidly at speed $v$ toward $+z$ obeys $\mathbf{E}(z,t) = \mathbf{E}\big(z - v(t - t_0),\ t_0\big)$; toward $-z$ the shift is $z + v(t - t_0)$. Check the direction with one feature: at a later time the front must be further along the direction of travel. In a lossless medium $v = c/\sqrt{\mu_r\epsilon_r}$ and $\eta = \sqrt{\mu/\epsilon} = \mu v$. For a plane wave travelling along $\hat{k}$, $\mathbf{H} = \hat{k}\times\mathbf{E}/\eta$, and $\mathbf{E}\times\mathbf{H}$ must point along $\hat{k}$.

(a) The pattern slides rigidly toward ${{params.dir_word}}$ at $v = {{params.v}}$ m/ns, so the field at $(z, t)$ is the snapshot value at the point it came from, $\zeta = z {{params.op}} v(t - t_0)$: $E_{ {{params.pol}} }(z,t) = F(\zeta)$.

  • Event 1: ${{{params.zeta1_line}}}$. This lies on the ramp ${{params.zA}} \lt \zeta_1 \lt {{params.zB}}$ m, where $F = E_0\,(\zeta - z_A)/(z_B - z_A)$ with $E_0 = {{params.E0}}$ V/m: $E_{ {{params.pol}} } = ({{params.E0}})\,\dfrac{ {{params.zeta1}} - ({{params.zA}}) }{ {{params.a}} } = {{params.E1_str}}\ \mathrm{V/m}$.
  • Event 2: ${{{params.zeta2_line}}}$. This lies on the ramp ${{params.zC}} \lt \zeta_2 \lt {{params.zD}}$ m, where $F = E_0\,(z_D - \zeta)/(z_D - z_C)$: $E_{ {{params.pol}} } = ({{params.E0}})\,\dfrac{ {{params.zD}} - ({{params.zeta2}}) }{ {{params.b}} } = {{params.E2_str}}\ \mathrm{V/m}$.
  • Event 3: ${{{params.zeta3_line}}}$, which lies outside ${{params.zA}} \lt \zeta \lt {{params.zD}}$ m, so $E_{ {{params.pol}} } = 0$. In words: the front is {{{params.front_word}}}. At $t_0$ it was at ${{params.front_t0}}$ m, and at $t = {{params.t3}}$ ns it was at ${{params.front_t0}} {{params.op}} {{params.v}}\,({{params.t0}} - {{params.t3}}) = {{params.front_t3}}$ m. The point $z = {{params.z3}}$ m was still ahead of it: the pulse had not arrived.

(b) At $t = t_0$ the expression must reduce to $F(z)$; that rules out the versions with $t$ or $t + t_0$ in place of $t - t_0$. As time goes on, every feature must move toward ${{params.dir_word}}$: a feature at $\zeta$ in the snapshot is at $z = \zeta {{params.nop}} v\,(t - t_0)$ at time $t$, so the argument of $F$ is $\zeta = z {{params.op}} v\,(t - t_0)$. The distance moved is $v$ times the elapsed time, not the elapsed time divided by $v$.

(c) The unchanged shape means the medium is lossless (part (e)), so $v = c/\sqrt{\epsilon_r}$ with $\mu_r = 1$, and $\epsilon_r = (c/v)^2 = \left(\dfrac{2.998\times10^{8}}{ {{params.v_tex}} }\right)^2 = {{params.eps_str}}$.

(d) $\eta = \sqrt{\mu_0/\epsilon} = \mu_0v = (4\pi\times10^{-7})({{params.v_tex}}) = {{params.eta_str}}\ \Omega$, the same as $\eta_0/\sqrt{\epsilon_r}$. So $|\mathbf{H}| = |E|/\eta = ({{params.absE1}}\ \mathrm{V/m})/({{params.eta_str}}\ \Omega) = {{params.H1_str}}\ \mathrm{mA/m}$. Direction: $\mathbf{H} = \hat{k}\times\mathbf{E}/\eta$ with $\hat{k} = {{params.k_vec}}$ and $\mathbf{E}$ along ${{params.E1_vec}}$ at this event, so $\mathbf{H}$ is along $({{params.k_vec}})\times({{params.E1_vec}}) = {{params.H_vec}}$. Check: $({{params.E1_vec}})\times({{params.H_vec}}) = {{params.k_vec}}$, the direction of travel.

(e) No. With $\sigma \gt 0$ the wave equation gains a loss term $\mu\sigma\,\partial\mathbf{E}/\partial t$, so a pulse would decay and distort as it moves. This one keeps its exact shape and size at a speed below $c$, which is what a lossless dielectric with $\epsilon_r = {{params.eps_str}}$ does. The slower speed comes from $\epsilon_r$, not from conduction, and the variation along the pulse is its shape, not attenuation.
